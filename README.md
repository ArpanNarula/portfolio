# Arpan Narula Portfolio

This is my personal portfolio built with Next.js, Tailwind CSS, and Framer Motion.

It highlights the projects I’ve worked on, the stack I use, a short experience section, and ways to reach me. The design is dark, clean, and a little more polished than a basic portfolio, but still meant to stay simple and fast.

## Projects on the site

- StockPilot AI
- EvalForge AI
- SupportOps Assistant
- CourtIQ
- Finio
- IMDB Sentiment Analysis

## Tech stack

- Next.js
- React
- Tailwind CSS
- Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in the browser.

## Build for production

```bash
npm run build
npm run start
```

## Folder structure

- `app/` - app router files and global styles
- `components/portfolio/` - reusable portfolio sections and UI components
- `public/` - static assets like preview image and resume

## Deployment

This portfolio is set up for Vercel deployment.
